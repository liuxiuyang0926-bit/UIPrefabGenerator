# 高精度还原

高精度模式按“结构分析 → 节点资源检索 → 资源与结构校正 → Builder → 本地视觉检查”执行。
两次 AI 会话均只读，只使用效果图及 Unity 导出的证据，不依赖 UnityMCP。
后台运行时固定本次 Panel、源图尺寸、内容哈希、资源根和生成配置。第二阶段开始前
累计用量达到 235,000 Token 时停止追加请求；窗口显示两阶段累计用量。

节点检索复用最终 Builder 的像素、遮挡、背景合成和九宫格评分。从全库快速排序中
精排 128 项，另外补充源尺寸几何候选，并确保所有显式候选都进入精排。
每个节点保留最多 12 项证据；低置信、图标、整图和结构风险节点展示最多 5 项，
高置信节点展示 1 项。联系图同时显示原图裁片、候选原始比例和目标尺寸渲染。
小型风险节点额外获得原始分辨率裁片。Container 和艺术字也参与证据探测。
候选顺序和同分决胜均确定化，不依赖文件枚举顺序。

1.1.2 起，纹理内容哈希、Sprite Rect、源尺寸、Border、PPU 与描述像素都相同的
重复资源在精排前合并为一个视觉候选，避免它们互相压低领先幅度或占满短名单。
相近但不同的原图、不同切片或 Border 不合并，原有可信度阈值保持不变。

## UISchema 扩展字段

字段均兼容旧 Schema，并经过精简序列化、重复展开和模板同构检查。

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| resourcePolicy | Auto | Auto / Candidate / Verified / ColorFallback |
| font | 空 | 已存在的 TMP_FontAsset 精确资源路径；空则沿用项目默认字体 |
| fontMaterial | 空 | 与字体图集相同的现有材质路径，可复用项目描边/阴影样式 |
| noWrap | false | 单行文本可设 true，禁止 TMP 自动换行 |
| lineSpacing | 0 | TMP 行距，与 characterSpacing 分开控制 |

AI 提交的 Verified 只有在矩形一致、资源库未变、独立本地匹配高置信且没有结构风险时
才能锁定；其余一律转换为 Candidate 并执行完整本地评分。资源库变化会使锁定证据失效。
Candidate 即使带 resource 也会先转入候选列表；全库中外观更好的资源仍可胜出。
ColorFallback 清空所有资源，只用于已确认的纯色。手工 Schema 的 Auto + resource
继续表示显式指定的资源，不改变人工选择。

显式路径在当前项目无法加载为 Sprite 时，会记录提示、解除锁定并重新检索。
有效显式 Sprite 优先于残留的 intentionalColor 标记；明确的 ColorFallback 仍保持纯色。
资源路径支持 Assets 和 Packages；多子 Sprite 图集始终使用 `路径#子Sprite名`，
即使子 Sprite 名称恰好等于图集文件名也不会省略选择器。

出现色块时，先检查窗口资源总目录和索引数量。图片文件存在但未导入为 Sprite
不能直接赋给 UGUI Image，工具不会擅自修改导入设置。报告中的“资源与字体提示”
会列出空索引、失效路径以及未匹配节点的最佳候选、分数和领先幅度。
本地图片分析提示自包含，不需要在目标工程复制 `.agents/skills`。

字体材质必须与实际字体共用非空图集。已有 Schema 中的有效字体和材质保持原样；
缺失字体依次回退到窗口选择的默认字体、当前 Schema 中已经验证的主要字体、项目默认字体。
窗口和 TMP Settings 均未指定字体时，才按稳定路径顺序查找项目中可用的 TMP 字体。
无效或不兼容的材质使用实际字体的默认材质，不中止整个 Prefab 生成。
这些替换会写入结果的 `Warnings`、Console 和还原检查报告，需要复核字体外观及字形覆盖。
生成器不按近似文件名猜字体，不修改共享字体材质，不改写输入 Schema，不自动缩小字号。
文字溢出由报告标记，避免用缩小字号掩盖错误的矩形。

AI 分析目前不接收字体资源清单，因此提示和导入器均禁止它指定 `font/fontMaterial` 路径；
新生成的文本使用当前项目配置。手工或已有 Schema 仍支持显式指定不同节点的有效字体。
AI 开始前会检查 TMP 必需资源；环境未配置时先给出导入指引，不等待分析完成再失败。

## 视觉检查

Builder 保存 Prefab 后，在独立 Preview Scene 中渲染 Generated 子树：

- Index.html：原图、生成结果、差异图及待复核节点；
- Preview.png：包含 TMP 文字的真实 UGUI 预览；
- Images.png：仅图像预览；
- Difference.png：可比较区域的差异热图；
- Report.json：逐节点矩形、颜色误差、边缘带误差、有效样本数和文字排版风险。

图像检查排除文字排版区域和后绘制图像区域，仅统计预览中不透明的像素。
无法确定宿主底色的半透明区域、完全遮挡区域会明确标为样本不足，不能算作通过。
未生成的运行时列表项、宿主页面等不属于整图相似度评价范围。
报告是差异定位工具，不是经过标定的整图还原率，也不会自动改写 Schema 或启动无界修复。
报告及测试结果只写入 Library，不成为运行时资源。重新生成仍只替换 Generated。

## 回归验证

菜单：`工具/UI工具/验证效果图还原流水线`。

验证器创建独立临时资源，覆盖第 100 项之后的 Sprite 召回、错误候选拒绝、
Verified 降级、文字字段往返、实际 UGUI 渲染、非默认 PPU/轴心九宫格、透明像素、
Prefab 保存与手工兄弟节点保留。完成或失败时均清理本次临时 Assets，并恢复项目适配器。
最近一次结果保存在 `Library/LxyUIEffectGenerator/Validation/Latest.txt`。

这组回归验证本地实现；具体美术稿仍需用新的高精度流程重新生成并对照报告确认。
